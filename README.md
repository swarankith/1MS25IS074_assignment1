# 🔍 Research Agent

An AI-powered research application designed to simplify information discovery, assist with research tasks, and help users explore information efficiently.

## 🚀 Overview

Research Agent is a web-based application that provides an interface for interacting with an AI-powered research system. It aims to make research easier by reducing manual effort and providing an accessible way to explore information.

## ✨ Key Features

- **AI-Powered Research:** Helps users with research-related queries.
- **Interactive Interface:** User-friendly web interface for interacting with the application.
- **Research Assistance:** Designed to simplify information gathering and exploration.
- **Full-Stack Application:** Combines frontend and backend components.

## 🛠️ Tech Stack

- Frontend: React / Vite
- Backend: Node.js
- Language: TypeScript
- Package Management: Bun

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd ResearchAgent
```

### 2. Install dependencies

```bash
bun install
```

### 3. Configure environment variables

Create a `.env` file using `.env.example` as a reference.

Add the required API keys and configuration values.

### 4. Run the application

```bash
bun run dev
```

Open the local URL displayed in your terminal.
